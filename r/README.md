## Mini Weather Data Analysis Project

## Project Overview
This project analyzes weekly weather data including temperature and rainfall using R.

## Tools Used
- R
- RStudio
- ggplot2
- R Markdown

## Skills Learned
- Data analysis using R
- Working with vectors and data frames
- Data cleaning and manipulation
- Summary statistics (mean, max, min, sum)
- Conditional statements (if/else)
- Loops (for loops)
- Data visualization using ggplot2
- Creating reports using R Markdown
- Basic reproducible data analysis workflow

## What I Did
- Created a dataset for weather data
- Calculated average, max, and min temperature
- Analyzed rainfall patterns
- Visualized temperature trends

## Key Insights
- Hottest day: Sunday (32°C)
- Total rainfall: 25mm
- 4 rainy days recorded

## How to Run
1. Open RStudio
2. Open the `.Rmd` file
3. Click "Knit" to generate report
