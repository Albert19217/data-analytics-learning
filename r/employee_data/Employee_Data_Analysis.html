Project Overview

This project analyzes employee productivity, salary distribution, and project workload using R and ggplot2.
The analysis includes data transformation, summary statistics, and visualization to uncover patterns in employee performance across departments.

Environment Setup

This analysis uses the following R packages:

  • dplyr for data manipulation
  • tidyr for data reshaping
  • ggplot2 for data visualization
  • knitr for table formatting
  • ggrepel for text labels readability

Transformation of Data

employee_data_clean <- employee_data %>%
  mutate(salary_per_project = salary / project,
         productivity = project / hoursworked,
         performance = ifelse(project >= 7, "Excellent",
                              ifelse(project >= 5 & project <= 6, "Good",
                                     "Average")))

Summary Analysis

The following analysis calculates department-level statistics including average salary, maximum salary, employee count, and productivity.

summary <- employee_data_clean %>%
  group_by(department) %>%
  summarise(
    avg_salary = mean(salary),
    max_salary = max(salary),
    min_salary = min(salary),
    total_project = sum(project),
    employeecount = n(),
    avg_productivity = mean(productivity)
  )

Summary & Recommendations

Key Findings

1. Experience drives salary (+47% gap)
Employees with 6–7 years of experience earn an average of $6,233 compared to $4,250 for those with 2–3 years. Retaining experienced employees yields a significant return.

2. Finance leads in compensation (22% above IT)
Finance averages $6,133 per employee vs IT at $5,025, despite similar project workloads. This pay gap may create an IT retention risk over time.

3. Significant productivity efficiency gap (3× difference)
Grace completes 8 projects in 175 hours; David completes 3 in 150 hours. High-efficiency employees are not compensated proportionally to their output.

4. Performance is individual, not departmental
40% of employees are rated Excellent, 40% Good, and 20% Average. No single department dominates performance ratings.

Recommendations

Priority Action Rationale
High Conduct IT salary audit IT workload matches Finance but salary lags 22% behind
High Introduce performance-based bonuses Top performers like Grace and Sarah are undercompensated relative to output
Medium Launch peer knowledge-sharing programme Pair Average-rated employees with Excellent-rated peers to raise team efficiency
Medium Replace simulated data with real HR records Enables scalable, automated reporting via SQL + R Markdown

Limitations

This analysis is based on a 10-person simulated dataset. Findings are directional only and should be validated against a larger real-world HR dataset before informing policy decisions. Salary figures are assumed to be monthly USD values.
